Wizard of Oz Protocol: Final Prototype V6

Purpose

This protocol explains how Canopy Pause simulates comfort-aware outdoor and indoor nature reset recommendations without building a live sensor system.

The final prototype uses Wizard-of-Oz simulation for:

  • weather comfort,
  • shade condition,
  • seating likelihood,
  • crowd level,
  • noise level,
  • breeze,
  • walking time,
  • group suitability,
  • indoor/window reset recommendation,
  • recent spot feedback,
  • shared group timer behaviour.

The prototype must not claim that these are live or guaranteed results. Use language such as:

  • Prototype estimate
  • Likely available
  • Checked recently
  • Recent spot feedback
  • Suggested option

Avoid:

  • guaranteed seating,
  • live sensor confirmed,
  • real-time occupancy verified,
  • exact availability.

Wizard Role

The participant should experience the prototype as if it is responding to campus comfort conditions, but the design must not imply that real sensors are operating.

Participant Task: Solo Flow

Participant scenario:

Imagine you have studied in the CDU library for around 70 minutes. You are tired, but you do not want to lose your study flow.

Participant should:

  1. Start from the Focus Session screen.
  2. Choose Use my usual reset or another reset option.
  3. Complete the Study Handoff screen:
    • Before I leave, I will finish...
    • When I return, I will resume...
  4. Review the usual reset recommendation.
  5. Start the reset.
  6. Follow the route/timer.
  7. Read the one-sentence nature-noticing prompt.
  8. Respond to the return cue.
  9. Resume using the saved task anchor.

Participant Task: Indoor Nature Flow

Participant scenario:

Imagine it is hot or uncomfortable outside, but you still want a short reset away from the screen.

Participant should:

  1. Notice or select Indoor Nature Reset.
  2. Review the reason for staying inside.
  3. Start the indoor timer.
  4. Read the window/nature prompt.
  5. Resume using the saved task anchor.

Participant Task: Group Flow

Participant scenario:

Imagine you are studying with two or three friends. The group has lost focus and wants a short break without it turning into a long chat.

Participant should:

  1. Choose Group Reset.
  2. Select group size and break length.
  3. Enter group handoff and group return task.
  4. Review the group spot recommendation.
  5. Understand Seats 2, space for 4 standing.
  6. Choose a sharing option:
    • Show QR code,
    • Copy timer link,
    • Start on this phone only.
  7. Start shared timer.
  8. Return using the group task anchor.
