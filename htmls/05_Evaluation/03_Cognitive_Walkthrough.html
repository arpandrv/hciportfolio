Cognitive Walkthrough

Purpose

This walkthrough checks whether a first-time user can understand and complete the final Canopy Pause V6 prototype without extra explanation. It focuses on learnability: whether users know what to do, can find the correct action, understand the feedback, and can continue through the flow.

Task 1: Start a Study-Safe Reset

User goal: Start a short reset without feeling forced to stop immediately.

Check Finding
Does the user know what to do first? Use my usual reset is the clearest first action.
Does "usual reset" make sense? The label could feel unclear without context.
Does the prompt feel pushy? Deep-focus users need control over timing.

Result: The first step is learnable because it gives a fast action while preserving user control.

Task 2: Complete the Study Handoff

User goal: Leave at a clear stopping point and know what to resume later.

Check Finding
Does the user understand why text is entered before leaving? Users need support for both stopping and returning.
Does the user know what to write? Examples help different study styles.
Does the user understand what happens next? The anchor must feel useful, not like extra admin.

Result: The handoff screen supports the core design problem: preserving the study thread.

Task 3: Understand the Usual Reset Recommendation

User goal: Decide whether the recommended reset is worth taking.

Check Finding
Does the user understand the recommendation? Place, reason, and total time need to be visible quickly.
Does the user understand comfort information? Plain tags are clearer than numeric scores.
Does the user understand the data is estimated? Users may over-trust comfort information.

Result: The recommendation is understandable if comfort information is practical and clearly labelled as an estimate.

Task 4: Change Reset Style

User goal: Choose a different reset type when the default does not fit.

Check Finding
Are the style options understandable? Closest, Quietest, Coolest, and Indoor Nature are clear.
Does the user understand trade-offs? Closest may be fast but less comfortable.
Does style choice add friction? Choosing every time would slow the flow.

Result: Style changing works as an optional control, not a required step.

Task 5: Follow the Reset Journey

User goal: Reach the reset spot without reading a complex map.

Check Finding
Does the user understand progress? A simple stage model is easier than map-heavy navigation.
Does the user know where to go? Landmark directions reduce confusion.
Is there a backup if outdoor conditions are unsuitable? Outdoor resets should not be forced.

Result: The journey is learnable because it gives enough direction without turning the app into a complex map.

Task 6: Complete the Nature Reset

User goal: Take a short break that connects to campus nature without becoming another phone activity.

Check Finding
Does the user know what to do during the reset? One sentence is easier than guided meditation.
Does the prompt feel connected to nature? The prompt should refer to real campus cues.
Does the screen encourage extra phone use? Extra controls could distract from the reset.

Result: The nature reset is understandable and appropriately lightweight.

Task 7: Return and Resume Study

User goal: End the break on time and restart study quickly.

Check Finding
Does the user know the break is over? The return cue must be explicit.
Does the user know what to resume? The task anchor must be visible.
Does the app avoid encouraging break drift? Extension can weaken the bounded break.

Result: The return flow supports momentum because the saved task is the main action.

Task 8: Indoor Nature Reset

User goal: Take a valid reset when going outside is too hot, rainy, crowded, or inconvenient.

Check Finding
Does the user understand why indoor is recommended? The reason should be plain.
Does indoor reset feel legitimate? It should not feel like a failed outdoor break.
Is nature still present? The flow must remain connected to the theme.

Result: Indoor Nature Reset supports comfort and safety while keeping the nature connection visible.

Task 9: Group Reset

User goal: Help a study group take a short break and return together.

Check Finding
Does the user know how to start group mode? Group Reset should be visible but not dominate the solo flow.
Does the group setup make sense? Group size, break length, and return task are enough setup.
Does the user understand group suitability? Capacity wording must be specific.
Does sharing make sense? Users expect quick sharing options.

Result: Group mode is learnable because it solves the social problem of returning without one person enforcing the break.
