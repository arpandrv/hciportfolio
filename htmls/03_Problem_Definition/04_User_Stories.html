User Stories

The stories are written for the proposed CDU study-break support system and focus on what students would need to trust, use, and return from short outdoor reset breaks.

Updated User Stories

ID User story Acceptance criteria
US1 As a student in a long study session, I want break prompts to appear at a suitable stopping point so that I am not interrupted in the middle of a difficult task. The user can choose a remind-after-current-task option. The user can snooze a prompt. The prompt does not force an immediate break. The system uses non-judgemental wording.
US2 As a student who worries about losing focus, I want to save one clear next step before leaving so that I can restart quickly when I return. Before the break starts, the user is asked to enter or select a short task anchor. The anchor can be as simple as a page number, question number, section, or next action. The same anchor appears on the return screen.
US3 As a student deciding whether to go outside, I want one clear nearby shaded option so that I do not waste energy choosing between too many places. The system shows one recommended option by default. The option includes walking time, total break time, and a simple route. The user can view more options only if they choose to.
US4 As a student studying in Darwin, I want to know whether the suggested spot has shade, seating, and comfortable conditions so that I do not end up standing in the heat. Each suggested spot shows confirmed shade status, seating availability, walking distance, and heat/weather warning. If comfort is poor, the system suggests an indoor fallback with a reason.
US5 As a student taking a short break, I want a clear timer and return reminder so that the break does not become open-ended. The user can start a 5, 7, or 10 minute timer. The timer includes walking and return time where relevant.The system gives a clear return cue at the end of the break.
US6 As a student who often defaults to phone scrolling or games, I want a low-distraction break activity so that I can rest without getting pulled into my phone. During the break, the screen shows only the timer, return cue, and one short nature-noticing prompt that can change sometimes with a smooth animation. The system avoids long text and unnecessary controls. The user can return to the task anchor quickly.
US7 As a student who prefers simple breaks, I want the app to feel low-effort so that using it does not feel like another task. The main break flow works with one or two taps. The user does not need to read a long explanation. The suggested route and total time are visible immediately.
US8 As a student who values a proper outdoor reset, I want to know whether a space is quiet or crowded so that the break feels restorative instead of distracting. Each outdoor spot can display quiet/crowd level such as quiet, moderate, or busy. The system can prioritise quieter spots when the user chooses a quiet reset preference.
US9 As a group study student, I want a group break mode so that everyone receives the same return signal and one person does not have to end the break. A group break can be started with a shared timer. The timer can be shown or shared with group members. The return prompt appears at the same time for the group. The suggested spot shows whether it suits multiple people.
US10 As a group study student, I want to know whether a suggested spot has enough space for several people so that the group does not arrive at a place that only works for one person. Suggested spots include a group-suitability tag such as solo, pair, or small group. Group mode does not recommend spaces that are too small for the selected group size.
US11 As a privacy-conscious student, I want location use to be optional and temporary so that I do not feel like the app is tracking me in the background. The user can use manual start location or opt-in location. Background tracking is off by default. The app explains that location is used only to suggest nearby spots.
US12 As a student taking an outdoor reset, I want a short nature prompt that isn't forced or sounds cheesy so that I can briefly notice the environment without feeling forced into a meditation exercise. The prompt is one sentence only. Examples include noticing breeze, shade, trees, or looking away from the screen. The prompt does not block the timer or return action.
US13 As a student under time pressure, I want to see the full time cost of the break before leaving so that I can decide whether I can afford it. The system shows total estimated time including walking, break duration, and return. The user can choose a shorter version if needed. Routes longer than the student’s limit are not recommended by default.
US14 As a student who does not know campus outdoor spots well, I want directions using simple landmarks so that I can find the place without studying a complex map. Suggested routes include plain-language cues such as "near this building" or "beside the tree area near the entrance"; the map view is simple and does not require advanced navigation.

Minimum Viable User Story Set

For the prototype, the most important stories to demonstrate are:

Prototype focus Related user stories Why this matters
Flow-sensitive break prompt US1 Students reject random interruptions, especially during deep work.
Task anchor and return screen US2 Returning to study is one of the strongest repeated needs across the participants.
One nearby shaded suggestion US3, US4, US13, US14 Students need comfort certainty before they will leave the library.
Bounded timer US5 Breaks often become longer than intended without a clear endpoint.
Low-distraction break screen US6, US12 The system should help students avoid phone-based distraction without forcing wellness language.
Privacy-friendly location use US11 Trust depends on optional and purposeful data use.
Optional group mode US9, US10 Group study has a different problem: social breaks extend unless everyone shares the same return signal.
Nature-noticing Prompt U12 Gives students a simple way to shift attention away from screens and notice the outdoor environment, while keeping the break short, and not overly “wellness” focused.
