Canopy Pause Portfolio Index

Project Overview

Project: Canopy Pause V6 - Study-Safe Nature Reset
Unit: HIT381 Human Computer Interaction and Design
Team: Group 24
Theme: Designs for Human-Nature Interaction

Canopy Pause is a mobile interaction design for CDU library students who study for long periods and need short, comfortable, nature-connected reset breaks without losing study momentum. The portfolio documents the project process from planning and discovery through problem definition, design iteration, prototyping, and evaluation.

Portfolio Structure

01_Project_Management

This folder documents team coordination, planning, ethics, and consent evidence.

  • 01_Team_Roles.md - Team member roles, responsibilities, shared work etc.
  • 02_Project_Timeline_and_Plan.md - Project stages, planning process, research preparation, design development, evaluation, and final submission preparation.
  • 03_Ethics_Documents/01_Ethics_Application.pdf - Ethics application.
  • 03_Ethics_Documents/02_Ethics_Clearance.pdf - Ethics clearance evidence.
  • 04_Consent_Forms - Participant consent-form evidence using participant codes P01-P10.

Access note: These ethics and consent files cannot be opened from this index because they contain personally identifiable information. To view these specific files, use the OneDrive link submitted in the assignment report. The rest of the portfolio links remain available for browsing here.

02_Discovery

This folder contains early user research and initial analysis of the problem space.

  • 01_Participant_Profiles.md - Summary profiles for participants P01-P10, including study patterns, break habits, barriers, scenarios, and prototype priorities.
  • 02_Interview_Transcripts.md - De-identified participant interview transcripts.
  • 03_Observation_Notes.md - Observation notes about indoor study contexts, break transitions, outdoor contexts, return issues, and design implications.
  • 04_Research_Questions_Answered.md - Synthesised answers to the main discovery research questions.

03_Problem_Definition

This folder shows how the team interpreted research findings and framed the design problem.

  • 01_Thematic_Analysis.md - Key research themes and design implications.
  • 02_Personas_and_Empathy_Maps.md - Personas, needs, behaviours, feelings, and implications for design.
  • 03_Problem_Statement_and_Design_Requirements.md - Final problem statement, design opportunity, requirements, and prototype priorities.
  • 04_User_Stories.md - User stories and minimum viable user story set.
  • 05_Scenarios_and_Storyboards.md - Scenarios and storyboard tables for solo study, comfort-aware reset, and group reset use cases.

04_Design

This folder documents ideation, concept selection, and prototype development.

  • 01_Ideation_and_Concept_Selection.md - Initial concepts, selection criteria, selected concept, and design rationale.
  • 02_Design_Iterations.md - Six prototype iterations from map-first reset finder to final study-safe nature reset.
  • 03_Prototype_Iterations_Link.md - Link to prototype iterations.

05_Evaluation

This folder documents evaluation planning, procedures, findings, and final concept refinement.

  • 01_Evaluation_Plan.md - Evaluation goals, tasks, measures and success criteria.
  • 02_Wizard_of_Oz_Protocol.md - Wizard-of-Oz setup, simulated states, and participant task flows.
  • 03_Cognitive_Walkthrough.md - Learnability review across the main prototype tasks.
  • 04_Heuristic_Evaluation.md - Heuristic evaluation findings and final responses.
  • 05_Prototype_6_Review_Responses.md - Participant responses to the final prototype.
  • 06_Final_Concept_Specification.md - Final product type, core tasks, feature specification and prototype boundaries.
