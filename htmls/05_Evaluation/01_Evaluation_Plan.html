Evaluation Plan

Project

Canopy Pause V6 is a mobile prototype for CDU library students who need short, comfortable, nature-connected reset breaks without losing study momentum.

This evaluation plan focuses on whether the final prototype is understandable, usable, trustworthy, and clearly connected to the human-nature interaction theme.

Evaluation Goals

Goal What the evaluation checks
Flow understanding Can users understand the pause-reset-return journey without extra explanation?
Study momentum support Does Study Handoff help users leave and return with a clear task anchor?
Comfort and trust Do users understand shade, seating, crowd, time, and comfort information as estimates?
Nature fit Do nature prompts feel short, grounded, and connected to campus nature rather than forced?
Efficiency Does the final flow feel quick enough for real study use?
Group support Does group reset make sense for shared breaks and returning together?

Core Evaluation Tasks

Task 1: Start a Study-Safe Reset

Participant scenario:

Imagine you have been studying in the CDU library for around 70 minutes. You are tired, but you do not want to lose your study flow.

Participant should:

  1. Notice the reset suggestion.
  2. Choose Use my usual reset or another suitable option.
  3. Complete Study Handoff:
    • what they will finish before leaving,
    • what they will resume when they return.

Task 2: Choose a Comfort-Aware Reset

Participant should:

  1. Review the usual reset recommendation.
  2. Interpret comfort tags such as shade, seating, breeze, crowd level, and total time.
  3. Understand that comfort information is a prototype estimate, not a guarantee.
  4. Choose outdoor reset, change style, or select Indoor Nature Reset if appropriate.

Task 3: Complete a Nature Reset and Return

Participant should:

  1. Start the reset journey.
  2. Follow the route and timer flow.
  3. Read the one-sentence nature prompt.
  4. Respond to the return cue.
  5. Resume using the saved task anchor.

Task 4: Test Group Reset

Participant scenario:

Imagine you are studying with two or three friends. The group has lost focus and wants a short break without it turning into a long chat.

Participant should:

  1. Choose Group Reset.
  2. Select group size and break length.
  3. Enter a shared return task.
  4. Review group suitability and capacity wording.
  5. Start or share the group timer.
  6. Return using the group task anchor.

Success Measures

Measure Success target
Task completion User completes the main solo flow without facilitator explanation.
Flow clarity User understands Study Handoff, recommendation, timer, return cue, and Resume Focus.
Trust User understands comfort data as estimated rather than guaranteed.
Nature fit User says the prompt is short, grounded, and connected to campus nature.
Return support User says the saved task anchor would help them resume study.
Efficiency User says the final flow feels quick enough or close to real use.
Group support User understands shared timer, capacity wording, and group return task.
