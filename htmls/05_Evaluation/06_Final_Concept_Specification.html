Final Concept Specification

Product Name

Canopy Pause V6: Final Study-Safe Nature Reset

Product Type

Canopy Pause is a mobile interaction prototype for CDU library students who study for long periods and need short, comfortable, nature-connected reset breaks without losing study momentum.

The final concept includes:

  • a mobile prototype,
  • comfort-aware outdoor and indoor reset recommendations,
  • Wizard-of-Oz simulated comfort data,
  • a short nature-noticing timer,
  • optional group reset support.

Final Design Problem

Students often recognise the need for a break only after their concentration has already dropped. They may avoid outdoor breaks because going outside feels uncertain or effortful, especially in Darwin heat, or because they fear losing their study flow.

The final design responds to this by supporting the complete pause-reset-return loop:

  1. pause at a suitable point,
  2. save the current study thread,
  3. choose a comfortable outdoor or indoor nature reset,
  4. keep the break short and bounded,
  5. return using a saved task anchor.

Core User Tasks

Task How the final prototype supports it
Start a study-safe reset The user starts from Focus Session and chooses Use my usual reset or changes reset style.
Protect study momentum Study Handoff asks what the student will finish before leaving and what they will resume after returning.
Choose a comfort-aware reset The app recommends one reset option and shows shade, seating likelihood, breeze, crowd level, walking time, total time, and estimate wording.
Complete a nature-connected reset The timer gives one short nature prompt, such as noticing breeze, shade, trees, or natural light.
Return and resume Return Cue and Resume Focus show the saved task anchor as the main next action.
Use group reset when needed Group mode supports group size, shared timer, capacity wording, and a shared return task.

Core Feature

Feature Purpose
Use My Usual Reset Gives the student a fast repeat-use path based on a previous or preferred reset style.
Study Handoff Captures both the stopping point and return point before the break begins.
Comfort-Aware Recommendation Shows one practical reset option with shade, seating, crowd, breeze, time, and estimate information.
Change Reset Style Allows the user to choose Closest, Quietest, Coolest, or Indoor Nature when the default does not fit.
Nature Reset Timer Keeps the break short while giving one low-effort prompt connected to campus nature.
Indoor Nature Reset Provides a valid reset when heat, rain, poor shade, or user preference makes outdoor breaks unsuitable.
Group Reset Helps small study groups take a bounded break with a shared timer and shared return task.
Why This Spot? Explains that recommendation data is estimated and avoids overclaiming live accuracy.

Prototype Boundaries

Implemented in the Prototype

  • Screen-to-screen mobile flow.
  • Study handoff.
  • Usual reset recommendation.
  • Reset style switching.
  • Indoor Nature Reset flow.
  • Group reset flow.
  • Timer, return cue, and resume screen.
  • Simulated comfort tags.

Simulated Through Wizard of Oz

  • Weather comfort.
  • Shade condition.
  • Seating likelihood.
  • Crowd and noise level.
  • Walking time and route comfort.
  • Group spot availability.
  • Recent spot feedback.
  • Shared timer behaviour.

Not Implemented

  • Real weather API integration.
  • Live shade detection.
  • Physical sensor network.
  • Real occupancy detection.
  • Real QR marker deployment.
  • Real-time background location tracking.
