Iteration 1: Map-First Reset Finder

Prototype intent

The first prototype tested whether students understood the basic idea of using an app to find a nearby shaded outdoor reset spot during a long library study session.

Feedback pattern

Users understood the concept, but many felt the prototype behaved too much like a campus map. The comfort score sounded too precise and the map/detail screen created decision effort.

Design problems

  • Too many spot choices.
  • Numeric comfort score was unclear.
  • Nature prompt felt secondary.
  • Privacy/location wording was weak.
  • Group mode felt unfinished.
  • Task anchor was useful but not central enough.

Iteration 2: Study-Flow First Reset

Prototype intent

Prototype 2 tested whether the app worked better when it focused first on protecting study flow rather than showing map data.

Feedback pattern

Users found this clearer than Prototype 1. They liked one recommended spot and understood plain comfort labels. However, they still said the flow had too many screens.

Design problems

  • Still too much tapping for a short break.
  • Break timing wording such as good pause point soon was vague.
  • Group mode still lacked detail.
  • Low-distraction break mode could be stronger.

Iteration 3: One-Tap Smart Reset

Prototype intent

Prototype 3 tested whether the app could feel faster and smarter while still being honest about simulated comfort data.

Feedback pattern

Users liked the faster flow and trusted smart data more when it was labelled as an estimate. They questioned how the app knew seats were free and wanted more control over what kind of reset was recommended.

Design problems

  • Best meant different things to different users.
  • Some wanted closest, others quietest, others coolest/shadiest.
  • Group mode was still not developed.
  • Change prompt risked encouraging more phone interaction.
  • Add 2 min could encourage break drift.

Iteration 4: Personalised + Group Reset

Prototype intent

Prototype 4 tested whether students preferred to guide the recommendation by choosing a reset style.

Main changes

Added reset styles:

  • Closest: lowest effort.
  • Quietest: calmer space.
  • Coolest: best shade and heat comfort.
  • Group-friendly: suitable for study groups.

Added group mode:

  • group size,
  • group task anchor,
  • group-suitable spot,
  • group capacity tags,
  • shared timer,
  • “keep voices low” reminder.

Feedback pattern

Users liked the control, especially Quietest and Coolest. Group users found group mode much more useful. However, several users said choosing a reset style every time added friction.

Design problems

  • Preference choice added a step.
  • Users wanted the app to remember their usual choice.
  • Group timer sharing needed clearer QR/link behaviour.
  • Group capacity wording needed more precision.
  • Indoor/window fallback still felt somewhat secondary.

Iteration 5: Usual Reset + Shared Timer

Prototype intent

Prototype 5 tested whether remembered preferences made the app feel more realistic and repeat-use friendly.

Main changes

  • Added Use my usual reset.
  • Added Usual reset: Coolest / Quietest / Closest / Indoor Nature.
  • Reframed fallback as Indoor Nature Reset.
  • Added clearer group capacity wording:
    • Seats 2, space for 4 standing.
  • Added share group timer screen:
    • Show QR code,
    • Copy timer link,
    • Start on this phone only.

Feedback pattern

Users found this version much quicker. They liked usual reset and the clearer group timer. Deep-focus users still wanted stronger support for deciding what to finish before leaving.

Design problems

  • “Usual reset” needed a clear explanation.
  • Users needed stopping-point support before leaving.
  • Add 2 min still risked break drift.
  • Indoor Nature Reset needed to feel intentionally nature-connected.

Iteration 6: Final Study-Safe Nature Reset

Prototype intent

Prototype 6 stabilised the final design.

Final changes

  • Kept Use my usual reset as the main action.
  • Added explanation:
    • Based on your last reset. Change anytime.
  • Added final Study Handoff screen:
    • Before I leave, I will finish...
    • When I return, I will resume...
  • Kept task anchor visible on timer, return cue, and resume screen.
  • Made Need 2 more minutes? a small secondary link.
  • Kept Indoor Nature Reset as a valid reset path.
  • Finalised group flow with QR/link sharing and group return cue.
  • Kept all nature prompts one sentence.
